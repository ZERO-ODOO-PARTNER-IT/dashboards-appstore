Sales Dashboard

KPI Dashboard for Sale Order Lines

This module adds a Dashboard menu under the Sales application. It provides key performance indicators (KPIs) based on the sale.order.line model.

Key Features

  • Total Sales Amount - Track your total revenue at a glance
  • Number of Orders - Monitor order volume over time
  • Average Order Value - Understand customer spending patterns
  • Top Selling Products - Identify your best performers
  • Sales by Status - View sales breakdown by order status
